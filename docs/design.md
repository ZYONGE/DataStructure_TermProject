# 촌수 계산기 (Korean Family Relationship Calculator)
## 프로젝트 설계 문서 (design.md)

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 촌수 계산기 |
| 언어 | C |
| 플랫폼 | Windows |
| UI 방식 | Windows Console API (TUI) |
| 작성일 | 2025 |

### 목표
사용자가 가족 구성원 정보를 입력하면 가족 구성도를 자료구조로 저장하고,
두 사람 사이의 촌수를 계산해 출력한다.
자료구조가 어떻게 구성되는지 UI로 실시간 시각화한다.

---

## 2. 자료구조 설계

### 2.1 핵심 구조 — 트리 + 이중연결리스트 혼합

실제 데이터 저장은 트리로, 같은 세대 형제자매 연결은 이중연결리스트로 구현한다.

```
수직 연결 (│) : 부모 → 자식     (트리)
수평 연결 (↔) : 형제자매 연결   (이중연결리스트)
배우자 연결 (─) : 부부 관계     (노드 내 spouse 포인터)
```

#### 구조 예시
```
        [할아버지]─[할머니]
               │
      ┌────────┴─────────────────┐
  [아버지]─[어머니]        [큰아버지]─[큰어머니]
      │           (이중연결)        │
  [나]↔[형]↔[누나]           [사촌]↔[사촌(여)]
```

---

### 2.2 노드 구조체

```c
typedef struct Person {
    char  name[50];           /* 이름                          */
    char  gender;             /* 'M' 남자 / 'F' 여자           */
    int   age;                /* 나이 (덱 삽입 기준)           */

    struct Person *parent;    /* 부모 포인터    (트리 - 위)     */
    struct Person *child;     /* 첫째 자식 포인터 (트리 - 아래) */

    struct Person *prev;      /* 왼쪽 형제자매  (이중연결리스트) */
    struct Person *next;      /* 오른쪽 형제자매 (이중연결리스트) */

    struct Person *spouse;    /* 배우자 포인터                 */
} Person;
```

---

### 2.3 자료구조별 역할

| 우선순위 | 자료구조 | 역할 | 구현 방식 |
|---|---|---|---|
| ★ Must | **트리** | 세대 간 부모-자식 수직 관계 저장 | 노드의 parent / child 포인터 |
| ★ Must | **이중연결리스트** | 형제자매 간 수평 연결 | 노드의 prev / next 포인터 |
| Should | **스택** | DFS 기반 촌수 탐색 경로 추적 | 연결 리스트 기반 스택 |
| Nice | **덱** | 세대별 UI 시각화 (나이 기준 정렬) | 이중연결 기반 덱 |
| Nice | **리스트** | 전체 구성원 목록 관리 및 검색 | 단순 연결 리스트 |

### 2.4 덱 UI 삽입 기준

각 세대를 하나의 덱으로 표현한다.
기준 인물(조부모 / 부모 / 본인)보다 나이가 많으면 front, 적으면 rear에 삽입한다.

```
조부모 세대 덱
front ──────────────────────────────── rear
 [큰할아버지]─[큰할머니]  [할아버지]─[할머니]  [작은할아버지]─[작은할머니]
       ↑ 나이 많음                                    나이 적음 ↑

부모 세대 덱
front ──────────────────────────────── rear
  [큰아버지]─[큰어머니]  [아버지]─[어머니]  [삼촌]─[숙모]  [고모]
       ↑ 나이 많음                                    나이 적음 ↑

본인 세대 덱
front ──────────────────────────────── rear
    [사촌형]  [형]  [나★]─[배우자]  [동생]  [사촌여동생]
       ↑ 나이 많음                         나이 적음 ↑
```

## 3. 촌수 계산 알고리즘

### 3.1 계산 방식
DFS(깊이 우선 탐색)로 나(기준점)에서 목표 인물까지의 경로를 탐색한다.
스택을 사용해 경로를 추적하고, 이동 횟수를 촌수로 환산한다.

```
나 → 아버지 → 할아버지 → 큰아버지 → 사촌
이동 횟수 : 4회 → 4촌
```

### 3.2 촌수 → 호칭 변환 범위
구현 범위를 4촌 이내로 제한한다.

```
1촌 : 부모, 자녀
2촌 : 형제자매, 조부모, 손자녀
3촌 : 큰아버지/삼촌/고모, 조카
4촌 : 사촌
```

### 3.3 호칭 결정 변수

```
① 촌수 (이동 횟수)
② 본인 성별   (M / F)
③ 상대방 성별 (M / F)
④ 상대방이 본인보다 위 세대 / 같은 세대 / 아래 세대
⑤ 부계 / 모계 여부
```

### 4.2 UI 구현 방식
- Windows Console API (`windows.h`) 사용
- `gotoxy()` 함수로 커서 이동
- `SetConsoleTextAttribute()` 로 색상 구분
- 추가 라이브러리 설치 없음

## 5. 기능 목록 (CRUD)

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 추가 | 가족 구성원 이름 / 성별 / 나이 입력 후 트리에 삽입 |
| 2 | 수정 | 이름으로 구성원 검색 후 정보 수정 |
| 3 | 삭제 | 이름으로 구성원 검색 후 트리에서 제거 |
| 4 | 조회 | 전체 구성원 목록 출력 |
| 5 | 촌수 계산 | 두 이름 입력 → DFS 탐색 → 촌수 숫자 출력 |
| 6 | 호칭 출력 | 촌수 + 성별 조건 → 한국어 호칭 출력 |
| 7 | 초기화 | 전체 트리 삭제 및 메모리 해제 |

## 7. 구현 우선순위

```
Phase 1 — 핵심 (Must)
├── Person 구조체 정의
├── 트리 삽입 / 삭제 / 탐색
└── 이중연결리스트 형제자매 연결

Phase 2 — 기능 (Should)
├── 스택 기반 DFS 촌수 계산
├── 4촌 이내 호칭 출력
└── CRUD 메뉴 구현

Phase 3 — 완성도 (Nice to have)
├── 덱 기반 세대별 UI 시각화
├── 리스트 기반 구성원 검색
└── Console API 색상 / 레이아웃 정리
```
