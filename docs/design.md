# 한국 가족 호칭 명세서

> **구현 범위**: 조부모 세대 ~ 본인 세대 (3세대)

---

## 1. 직계 (直系) — 상향

직계는 세대와 성별로 호칭이 결정된다.

### 1-1. 상향 직계

| 호칭 | 한자 | 조건 |
|---|---|---|
| **부** | 父 | 부모 세대, 남성 |
| **모** | 母 | 부모 세대, 여성 |
| **조부** | 祖父 | 조부모 세대, 남성 |
| **조모** | 祖母 | 조부모 세대, 여성 |

---

## 2. +1세대 방계 — 부모 항렬

### 2-1. 3촌

분기 기준: **아버지와의 나이 비교** 및 **성별**

| 호칭 | 한자 | 조건 |
|---|---|---|
| **백부** | 伯父 | 아버지의 형제, **아버지보다 연상** |
| **숙부** | 叔父 | 아버지의 형제, **아버지보다 연하** |
| **고모** | 姑母 | 아버지의 자매 (여성) |

> **주의 1**: 백부/숙부는 아버지(부)와의 나이 비교로 결정된다.
> **주의 2**: 구어(삼촌)와 한자어(숙부)가 갈리는 지점이 여기다.

---

## 3. 동항렬 (同行列) — 나와 같은 세대

### 3-1. 2촌 (형제자매)

분기 기준: `target.gender` × `birth_year` 비교 (나의 성별은 호칭에 영향 없음)

| 호칭 | 한자 | 조건 |
|---|---|---|
| **형** | 兄 | target 남성, 연상 |
| **제** | 弟 | target 남성, 연하 |
| **자** | 姊 | target 여성, 연상 |
| **매** | 妹 | target 여성, 연하 |

> **주의**: 한자어에서는 형/오빠 → 모두 **형(兄)**, 누나/언니 → 모두 **자(姊)**.

---

### 3-2. 4촌 — 종형제 계열

분기 기준: **조부의 어느 자녀를 경유했는지** (남성 경유 vs 고모 경유)

**백부·숙부 경유 (남성)**

| 호칭 | 한자 | 조건 |
|---|---|---|
| **종형** | 從兄 | target 남성, 연상 |
| **종제** | 從弟 | target 남성, 연하 |
| **종자** | 從姊 | target 여성, 연상 |
| **종매** | 從妹 | target 여성, 연하 |

**고모 경유 (여성)**

| 호칭 | 한자 | 조건 |
|---|---|---|
| **고종형** | 姑從兄 | target 남성, 연상 |
| **고종제** | 姑從弟 | target 남성, 연하 |
| **고종자** | 姑從姊 | target 여성, 연상 |
| **고종매** | 姑從妹 | target 여성, 연하 |

> **종형제 통칭 원리**:
> - 백부/숙부 자녀 → **종형제(從兄弟)**
> - 고모 자녀 → **고종형제(姑從兄弟)**

---

## 4. 배우자 호칭 — 후처리 교체 테이블

배우자 호칭은 혈족 호칭을 먼저 결정한 뒤 아래 표로 변환한다.

| 혈족 호칭 | 배우자 호칭 | 비고 |
|---|---|---|
| 백부 (伯父) | **백모 (伯母)** | 큰어머니 |
| 숙부 (叔父) | **숙모 (叔母)** | 작은어머니 |
| 고모 (姑母) | **고모부 (姑母夫)** | 혈족이 여성이므로 `부(夫)` 접미 |

> **배우자 호칭 생성 원칙**:
> - 윗 항렬 **남성** 혈족의 배우자: 접미사 `부(父)` → `모(母)` 로 교체
> - 윗 항렬 **여성** 혈족의 배우자: 호칭 뒤에 `부(夫)` 를 추가

---

## 5. 한자어 구성 원리 요약 (구현 범위 내)

| 접두사/접미사 | 의미 | 예시 |
|---|---|---|
| **백(伯)** | 아버지보다 손위 남자 형제 | 백부, 백모 |
| **숙(叔)** | 아버지보다 손아래 남자 형제 | 숙부, 숙모 |
| **고(姑)** | 아버지의 여자 형제 (친가) | 고모, 고모부 |
| **종(從)** | 1단계 방계 (공통 조상: 조부) | 종형, 종제, 종자, 종매 |
| **고종(姑從)** | 고모 경유 방계 | 고종형, 고종제 |

---

## 6. 같은 촌수, 다른 호칭 — 핵심 케이스 정리 (구현 범위 내)

| 촌수 | 관계 | 호칭 | 차이 원인 |
|:---:|---|---|---|
| 3촌 | 아버지의 형 (연상 남자 형제) | **백부** | 아버지보다 연상 |
| 3촌 | 아버지의 동생 (연하 남자 형제) | **숙부** | 아버지보다 연하 |
| 3촌 | 아버지의 자매 | **고모** | 여성 |
| 4촌 | 백부·숙부의 자녀 | **종형/종제/종자/종매** | 남성 친족 경유 |
| 4촌 | 고모의 자녀 | **고종형/고종제/고종자/고종매** | 고모(여성) 경유 |
