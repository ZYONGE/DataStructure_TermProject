## 프로젝트 개요

**주제**: 아직 미정

**목적**: 자료구조의 기본 개념과 구현 방법을 이해하고, 다양한 자료구조를 활용하여 데이터를 효율적으로 관리하는 방법을 학습한다.

**컴파일 방법**: 

## 사용 자료구조

- 배열
- 스택
- 큐
- 덱
- 트리
- 그래프

## 자료구조 구현 방식

- 이중 연결 구조
- 노드

## 구현 기능

### 필수 기능

- insert (삽입)
- delete (삭제)
- search (검색)
- display (출력)
- sort (정렬)
- import (가져오기)

### 추가 기능 (검토 중)

- 계산
- 제 3의 값 추출
- 데이터 분석
- 데이터 예상
- 자료 저장 상태 확인
