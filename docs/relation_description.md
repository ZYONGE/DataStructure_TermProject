# 가족 관계 및 촌수 정의 규칙

## 1. 기본 원칙 (촌수 계산법)

촌수(寸數)는 친족 간의 멀고 가까움을 나타내는 거리의 척도입니다.

- **수직 이동 (직계 혈족)**: 나를 기준으로 부모 또는 자식으로 이동할 때마다 +1촌씩 증가합니다.
- **수평 이동 (방계 혈족)**: 형제자매 간의 촌수는 직접 연결되지 않고, 부모를 거쳐야 하므로 나와 부모(+1) + 부모와 형제자매(+1) = 2촌이 됩니다.
- **배우자 (무촌)**: 부부 사이는 촌수가 없는 **무촌(0촌)**입니다. 따라서 혈족의 배우자(예: 숙모, 고모부 등)는 혈족과 동일한 촌수로 취급하되, 호칭(문자열)으로만 부르고 숫자 인덱스는 표기하지 않습니다.

**표현 방식 규칙:**

- **직계 (수직 관계)**: 문자열 표현만 사용 (1촌, 2촌 등 숫자 표기 안 함)
- **방계 (수평 이동 포함)**: 3촌 이상부터는 '숫자+촌' 형태의 인덱스와 특정 호칭(문자열)을 혼용 (예: 3촌=삼촌, 4촌=사촌)

---

## 2. 수직 관계 (직계 가족 — 문자열 표현만 사용)

직계 가족은 촌수를 계산할 수는 있으나, 실제로 숫자로 부르지 않고 고유 호칭만 사용합니다.  
어머니 쪽(외가)의 경우 '외(外)' 자를 붙여 구분합니다.

| 계층 (수직 거리) | 남자 (친가 / 외가) | 여자 (친가 / 외가) | 비고 |
|:---:|---|---|---|
| +3 (증조부모) | 증조할아버지 / 외증조할아버지 | 증조할머니 / 외증조할머니 | |
| +2 (조부모) | 할아버지 / 외할아버지 | 할머니 / 외할머니 | |
| +1 (부모) | 아버지 | 어머니 | |
| 0 (나 및 배우자) | 나 (본인) / 남편 | 나 (본인) / 아내 | 무촌 (0촌) |
| -1 (자식) | 아들 | 딸 | |
| -2 (손자녀) | 손자 / 외손자 | 손녀 / 외손녀 | 딸의 자녀는 '외'를 붙임 |
| -3 (증손자녀) | 증손자 / 외증손자 | 증손녀 / 외증손녀 | |

## 3. 수평 관계 포함 (방계 가족 — 숫자 인덱스 사용 가능)

수평(형제) 관계가 섞이는 순간 방계 혈족이 되며, 이때부터 촌수 개념이 적극적으로 사용됩니다.

### 2촌: 형제자매 (나 → 부모 → 형제자매)

형제자매는 2촌이지만 숫자 인덱스로 부르지 않고, 성별과 나이에 따른 고유 호칭을 사용합니다.

- **내가 남자일 때:**
  - 남자: 형 (연상), 남동생 (연하)
  - 여자: 누나 (연상), 여동생 (연하)
- **내가 여자일 때:**
  - 남자: 오빠 (연상), 남동생 (연하)
  - 여자: 언니 (연상), 여동생 (연하)

### 3촌: 부모의 형제자매 및 나의 조카

> 나 → 부모(+1) → 조부모(+1) → 부모의 형제(-1) = **3촌**

**[아버지 측 (친가)]**

- 아버지의 남자 형제:
  - 미혼: 삼촌 (숫자 인덱스가 그대로 호칭으로 굳어진 사례)
  - 아버지보다 형인 경우 (기혼): 큰아버지 (백부) / 배우자는 큰어머니 (백모)
  - 아버지보다 동생인 경우 (기혼): 작은아버지 (숙부) / 배우자는 작은어머니 (숙모)
- 아버지의 여자 형제: 고모 / 배우자는 고모부

**[어머니 측 (외가)]**

- 어머니의 남자 형제: 외삼촌 / 배우자는 외숙모
- 어머니의 여자 형제: 이모 / 배우자는 이모부

**[하향 이동 — 조카]**

- 형제자매의 자녀 (나 → 부모 → 형제 → 자녀): **조카** (3촌) — 성별에 따라 남조카, 여조카

### 4촌: 부모님 형제자매의 자녀 (사촌)

> 나 → 부모(+1) → 조부모(+1) → 부모의 형제(-1) → 그들의 자녀(-1) = **4촌**

4촌부터는 인덱스(사촌)를 기본으로 하고, 부모의 성별 관계에 따라 접두사가 붙습니다.

| 접두사 | 경로 | 호칭 |
|---|---|---|
| 친사촌 (종형제) | 아버지의 남자 형제(큰아버지/작은아버지)의 자녀 | 사촌 형/누나/오빠/동생 |
| 고종사촌 | 아버지의 여자 형제(고모)의 자녀 | 고종사촌 형/누나/오빠/동생 |
| 외사촌 | 어머니의 남자 형제(외삼촌)의 자녀 | 외사촌 형/누나/오빠/동생 |
| 이종사촌 | 어머니의 여자 형제(이모)의 자녀 | 이종사촌 형/누나/오빠/동생 |

> 4촌 간에도 나이와 성별에 따라 형, 누나, 오빠, 동생 등의 호칭을 함께 사용합니다.

## 4. 확장된 수평 관계 (할아버지의 방계 혈족)

할아버지의 형제자매와 그 자녀들은 공통 조상이 **증조부모**로 올라가며, 촌수와 호칭 규칙이 한 단계 더 확장됩니다.  
이 범위부터는 촌수(숫자)와 호칭(문자열)이 결합된 **'당(堂)'** 또는 **'종(從)'** 접두사가 본격적으로 등장합니다.

### 4촌: 할아버지의 형제자매 (조부모 항렬)

> 나 → 부모(+1) → 조부모(+1) → 증조부모(+1) → 할아버지의 형제자매(-1) = **4촌**

계산상 4촌이지만, 나보다 두 세대 위(조부모 항렬)의 어른이므로 숫자 인덱스를 직접 호칭으로 쓰지 않고 존칭이 담긴 고유 문자열을 사용합니다.

**[친가 — 할아버지의 형제자매]**

- 남자 형제 (종조부):
  - 할아버지보다 형인 경우: 큰할아버지 / 배우자는 큰할머니
  - 할아버지보다 동생인 경우: 작은할아버지 / 배우자는 작은할머니
- 여자 형제: 대고모 (왕고모) / 배우자는 대고모부 (왕고모부)

**[외가 — 외할아버지의 형제자매]**

- 남자 형제: 외종조부
- 여자 형제: 외대고모

### 5촌: 할아버지 형제자매의 자녀 (부모 항렬)

> 나 → 부모(+1) → 조부모(+1) → 증조부모(+1) → 할아버지의 형제자매(-1) → 그들의 자녀(-1) = **5촌**

이들은 나의 부모님과 사촌 지간입니다. 부모님 세대이지만 '5촌'이라는 숫자 인덱스를 호칭에 적극적으로 섞어 쓰며, **'당(堂)'** 또는 **'종(從)'** 접두사로 직계 혈족(삼촌/고모)과 구분합니다.

**[친가 — 할아버지 남자 형제의 자녀]**

- 남자 (아버지의 사촌 형제): 당숙 / 종숙 — 일상에서는 "5촌 당숙", "5촌 아저씨"로 부름 / 배우자는 당숙모 (종숙모)
- 여자 (아버지의 사촌 누이): 당고모 / 종고모 — 일상에서는 "5촌 고모"로 부름

**[외가 및 기타 5촌]**

- 아버지의 고종사촌 (대고모의 자녀): 내종숙 — 일상에서는 5촌 아저씨/고모로 통칭
- 어머니의 사촌 형제 (외할아버지 형제의 자녀): 외당숙 / 외종숙 (5촌 외삼촌)
- 어머니의 사촌 누이: 외당고모 (5촌 이모)

### 6촌: 당숙·당고모의 자녀 (재종형제)

> 당숙(5촌)의 자녀: $Y = 3$이 되어 총 **6촌**

나와 같은 세대이므로 부모님들의 관계(당숙)를 이어받아 **재종형제(6촌 형제)**가 됩니다. (예: 육촌 형, 육촌 동생)

## 5. 확장된 규칙 알고리즘 (증조부모 공통 조상 기준)

이전에 정의한 공통 조상 찾기 알고리즘 $X + Y = 촌수$를 그대로 적용하되, 호칭 부여 시 **항렬(세대 차이)**을 고려하는 규칙이 추가됩니다.

**1. 거리 계산**

- 나로부터 증조부모까지 올라가는 세대 수: $X = 3$
- 증조부모로부터 대상까지 내려가는 세대 수: $Y$
- 촌수 = $3 + Y$

**2. 항렬(세대)에 따른 호칭 적용 규칙**

| $Y$ | 촌수 | 항렬 | 호칭 규칙 |
|:---:|:---:|---|---|
| 1 | 4촌 | 조부모 항렬 (나보다 2세대 위) | 숫자 인덱스 사용 불가. '종조(從祖)' 접두사 + 부/모 호칭 (큰할아버지, 작은할아버지) |
| 2 | 5촌 | 부모 항렬 (나보다 1세대 위) | 숫자 인덱스(5촌) 사용 가능. '당(堂)' 또는 '종(從)' 접두사 + 숙/고모 호칭 (당숙, 당고모) |
| 3 | 6촌 | 나와 같은 세대 | 재종형제 — '육촌 형', '육촌 동생' 등으로 표현 |

## 6. 세대별 가족 관계 및 호칭 리스트 (+3세대 ~ -3세대)

증조부모(3세대 위)부터 증손자녀(3세대 아래)까지, 공통 조상인 증조부모 범주 내(전통적 개념의 '당내(堂內)')의 모든 친족 관계 리스트입니다.

### 6.1. +3 세대 (증조부모 항렬)

나의 3세대 위 어른들이며, 당내 친족의 최상위 공통 조상 세대입니다.

| 촌수 | 관계 설명 | 호칭 (남자) | 호칭 (여자) | 표기 및 호칭 규칙 |
| :---: | :--- | :--- | :--- | :--- |
| **직계** | 조부모의 부모 (나의 증조부모) | 증조할아버지 (증조부) | 증조할머니 (증조모) | 직계이므로 문자열 고유 호칭만 사용 |
| **5촌** | 증조부모의 형제자매 | 종증조부 | 증대고모 (왕고모) | 항렬이 높은 어른이므로 숫자 인덱스(5촌)로 직접 부르지 않음 |

### 6.2. +2 세대 (조부모 항렬)

나의 2세대 위 어른들입니다.

| 촌수 | 관계 설명 | 호칭 (남자) | 호칭 (여자) | 표기 및 호칭 규칙 |
| :---: | :--- | :--- | :--- | :--- |
| **직계** | 부모의 부모 (나의 조부모) | 할아버지 (조부) / 외할아버지 | 할머니 (조모) / 외할머니 | 직계이므로 문자열 고유 호칭만 사용 |
| **4촌** | 조부모의 형제자매 | 종조부 (큰/작은할아버지) | 대고모 (왕고모) | 항렬이 높으므로 '사촌할아버지'와 같은 숫자 표기는 지양 |
| **6촌** | 증조부 형제의 자녀 | 재종증조부 | 재종증조모 | 일상에서는 보통 '할아버지/할머니'로 통칭 |

### 6.3. +1 세대 (부모 항렬)

나의 1세대 위 어른들입니다. 이때부터 촌수 인덱스를 일상 호칭에 적극적으로 결합하여 사용합니다.

| 촌수 | 관계 설명 | 호칭 (남자) | 호칭 (여자) | 표기 및 호칭 규칙 |
| :---: | :--- | :--- | :--- | :--- |
| **직계** | 나를 낳아주신 부모 | 아버지 (부) | 어머니 (모) | 직계이므로 호칭만 사용 (1촌 표기 안 함) |
| **3촌** | 부모의 형제자매 | 백부(큰아버지) / 숙부(작은아버지) / 외삼촌 | 고모 / 이모 | 호칭과 인덱스(**삼촌**)를 혼용하여 사용 |
| **5촌** | 조부모 형제의 자녀 (부모의 사촌) | **당숙 (종숙)** / 외당숙 | **당고모 (종고모)** / 외당고모 | 일상에서 **"5촌 당숙"**, **"5촌 아저씨/고모"**로 혼용 |
| **7촌** | 증조부 형제의 손자 (부모의 육촌) | 재당숙 (재종숙) | 재당고모 | 일상에서 **"7촌 아저씨/고모"**라고 인덱스 기반으로 부름 |

### 6.4. 0 세대 (본인 항렬)

나와 세대가 같은 형제, 자매 및 사촌 관계입니다. 촌수가 항상 짝수로 떨어집니다.

| 촌수 | 관계 설명 | 호칭 (내가 남자일 때) | 호칭 (내가 여자일 때) | 표기 및 호칭 규칙 |
| :---: | :--- | :--- | :--- | :--- |
| **0촌** | 본인 및 배우자 | 나 / 아내 | 나 / 남편 | 부부 사이는 무촌 |
| **2촌** | 부모가 같은 형제자매 | 형 (연상) / 남동생 (연하)<br>누나 (연상) / 여동생 (연하) | 오빠 (연상) / 남동생 (연하)<br>언니 (연상) / 여동생 (연하) | 2촌이지만 고유 호칭이 있으므로 숫자 인덱스 미표기 |
| **4촌** | 부모 형제의 자녀 | 종형제자매 (친사촌)<br>외사촌 / 고종사촌 / 이종사촌 | ← 동일 | **"사촌 형/누나/동생"** 등 인덱스 기반 호칭 사용 |
| **6촌** | 조부모 형제의 손자 | 재종형제자매 | ← 동일 | 일상에서 **"육촌 형/동생"**으로 명확히 인덱스 표기 |
| **8촌** | 증조부 형제의 증손 | 삼종형제자매 | ← 동일 | 일상에서 **"팔촌 친척"**으로 표현. 당내친의 마지노선 |

### 6.5. -1 세대 (자식 항렬)

나의 1세대 아래인 자녀 및 조카 세대입니다. 지칭할 때는 아래 명칭을 쓰며, 보통 이름을 부릅니다.

## 요약 규칙 (알고리즘화)

1. 나와 대상 간의 **공통 조상**을 찾는다.
2. 나로부터 공통 조상까지 올라가는 세대 수 $X$를 센다.
3. 공통 조상으로부터 대상까지 내려가는 세대 수 $Y$를 센다.
4. $X + Y$ = **촌수**가 된다.
5. $X = 0$ 이거나 $Y = 0$ 이면 직계이므로 **호칭(문자열)만 사용**한다.
6. 대상이 혈족의 배우자라면, 혈족의 촌수를 그대로 차용하되 **호칭(문자열)만 사용**한다.
